20 animation recipes — implicit, explicit, hero, physics and shared-axis motion.

**Lane:** Flutter · **Live demo:** https://android-flutter-animations.hanzo.app

## Run it on Android

```sh
flutter run -d android
```

## Provenance

Forked from [flutter/samples](https://github.com/flutter/samples) — `animations`, licensed **BSD-3-Clause**.
The upstream `LICENSE` is kept verbatim in this repo; the copyright stays with
its authors. Changes made here are limited to what a standalone fork needs
(see the initial commit).

## Preview

`flutter build web --release` produces the static bundle served at
https://android-flutter-animations.hanzo.app — the same app the Android build runs, rendered by
CanvasKit. It is a real running app, not a screenshot.
